# 单一工作台与分析复用 · 交互设计稿

状态：待用户确认后实现。日期：2026-10-19。本目录仅包含设计稿，不代表原生应用已经实现。

打开 [交互设计稿](prototype.html)，切换 Mac／iPhone 和八个评审状态。编号是评审入口，不是产品页面导航。全部人物、项目缩略图及时间轴采用绘制素材；品牌图来自现有 BrandLogo。状态、进度、播放与导出均为交互演示，不执行真实视频分析或编码。

## 同一工作台的状态

1. 选择主角与片段：完整显示原片，在画面点击主角，通过时间轴两端截取。仅提供选人提示和“分析所选片段”，不显示构图、打码或常驻框选入口。
2. 分析中：分析选中范围的人群信息。底部暂停按钮与进度状态并排，仅在状态按钮内显示百分比和填充进度，不重复展示进度卡片。
3. 分析暂停：保留分析进度，提供并排的“返回选择／继续分析”。
4. 构图与打码：分析完成后显示设置，仅提供构图／打码工具，不重复选人。所有设置即时生效，工具切换保留选择，无面板级取消／完成。生成由独立按钮触发。
5. 生成中：复用人物分析，按当前设置编码；取消与生成进度并排显示，取消返回设置。进度只展示一次。
6. 预览与导出：播放已生成的视频，提供“返回修改／导出视频”。导出保存已有成片，不重复分析或编码。
7. 返回修改：保留分析和设置，修改后重新生成。已有成片不能伪装为新设置的预览，新成片完成后再替换。
8. 确认主角：未识别到主角或身份不确定时停在问题帧；点击人物或手动框选后确认继续。未指定时确认按钮禁用，不越过问题帧。真实功能中的框选必须解析为有效人物候选，不能直接当作稳定轨迹。

## 视觉与切换

- iPhone 与 Mac 共用同一工作台状态及功能依赖；Mac 保留左侧视频／时间轴与右侧设置分栏，iPhone 保持应用内部不滚动。
- 操作区按内容紧凑排布，避免固定空白。设置展开时视频与时间轴平滑让位，不能遮挡时间轴。
- 独立动作使用独立玻璃按钮，不用大卡片包裹状态和按钮。设置内容保留玻璃面板。
- 比例、构图／打码、遮挡范围和样式使用一体式玻璃分段控件：共享胶囊底座及单个浮动选中滑块，不能拆成独立按钮。
- 状态过渡约 280–320ms，分段滑块约 280ms；尊重系统减少动态效果。HTML 使用 CSS／Web Animations 模拟，原生实现复用现有 SwiftUI 玻璃组件与动画。
- 图片样式直接使用当前内置 Logo，不打开图片页面或系统选择器；显示素材缩略图与名称，为后续增加素材留出空间，不显示空添加入口。

## 后续功能实现约束

分析结果需持久化到项目；重复设置不重新分析，暂停恢复不重复扫描已完成范围。时间范围落在已分析区间内则复用，超出部分只补分析缺失片段；更换主角优先复用人群观测，身份不确定仍需确认。原片替换、数据损坏或格式不兼容应说明无法复用原因，不静默重分析。

分析、生成分别处理进度、取消、恢复与失败。异步任务须保留任务 ID／项目 ID 校验，并检查晚到回调、项目切换、后台和删除。构图和打码更新按依赖独立进行；动态预览与真实输出的一致性仍需功能实现和真实视频验证。
