# 玻璃切换与视频连续性

## 修改

- 比例与底部工具选中态使用原生 Liquid Glass、共享 glassEffectID 和 matchedGeometry 过渡，替换普通材质高亮。标签放在玻璃效果内容内部，避免材质遮挡文字。
- 全览和构图共用同一个视频视图位置与 AVPlayerLayer；切换时只动画调整取景框、源画面尺寸和偏移。不再用条件分支替换整个视频组件。
- PlayerSurface 仅在播放器实例真正改变时重新绑定；比例与对应裁剪区域在同一个状态事务内更新，避免先改变比例再等待异步裁剪。
- 暂停画面保持原视频层，预览播放层单独复用。设置切换不反复弹出加载指示。保留手势、截取、独立轴居中及预览／导出共用的最终裁剪参数。
- 减少动态效果时关闭过渡；减少透明度和旧系统使用材质回退。

## 验证

- 构图单元、比例、手势确认取消、截取回归通过：[结果](regression-summary.json)。玻璃文字渲染修正后，三个比例的界面回归再次通过：[结果](label-summary.json)。
- 最终 iPhone 17 Pro 模拟器使用3840×2160桌面原片，反复切换三个比例及全览／构图，两轮通过，0失败：[结果](final-summary.json)。
- 最终录屏中央共同画面区域以60fps重采样检查1034帧，未检出全黑帧。判定为该区域98%以上像素亮度低于12；这是录屏区域检查，不代表真机帧率测量或任意视频场景的保证：[检查记录](frame-check.json)。
