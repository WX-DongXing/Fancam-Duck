# 时间轴与编辑工具精简验证

## 本轮行为

- 移除独立「片段」入口，在视频时间轴两端直接拖动截取，拖动时预览边界画面，松手保存。
- 构图中同样支持截取；取消构图保留已经保存的时间范围。
- 移除「运镜」入口，保留跟随与平滑算法，新项目默认柔和；已有项目明确保存的速度不覆盖。
- 底部保留「选人」「构图」，主操作改为带文字的玻璃胶囊：「开始处理」「确认并处理」或「预览成片」。
- 编辑页保持单屏不滚动，初始展示原片全览；不确定目标时暂停处理并在人物上重新选择。
