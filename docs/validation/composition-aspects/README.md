# 构图画幅与轻量选框验证

## 本轮调整

- 未选人物使用白色四角标记，移除粗黑白双边框及填充；已选人物保留黄色框。
- 构图可选 9:16、16:9、4:3、1:1。画布、镜头轨迹、输出画质及导出共用持久化画幅字段。旧项目默认兼容为 9:16。
- 切换画幅尽量保留取景中心和高度，超过源视频边界时收缩并限制位置；同步更新该画幅的编码尺寸，不自动放大源视频。
- 水平居中、垂直居中各自调整参考帧舞者中心，保留另一轴和缩放。
- 移除「全身优先」开关。自动取景保留全身留白；手动构图以用户取景为准，不因全身保护自动拉远。源边界及目标中心可见约束仍保留。
- 固定单屏布局，大字号下限制紧凑工具区的字号增长并允许标签缩小，避免相互覆盖。

## 验证结果

- iPhone 16e / iOS 26.3.1 模拟器：68 项单元测试和 8 项交互测试通过，6 项条件测试跳过，0 失败。[回归结果](regression-summary.json)
- iPhone 17 Pro 模拟器：22 项相关单元测试及 2 项 UI 测试通过，0 失败。其中桌面原视频派生的方形 5 秒与竖屏 6 秒视频分别完成 16:9、4:3 的相册导入、选人、构图、处理、预览与真实导出。[真实视频结果](real-summary.json)
- 最终工具排版调整后，最大辅助字号、四种画幅切换与取消恢复 2 项交互复测通过，0 失败。[最终结果](final-summary.json)
- 四种画幅均使用测试视频实际编码并检查输出尺寸与预览 renderSize 一致；几何测试验证裁剪不越界、手动参考取景保持及旧数据兼容。没有以界面截图替代编码验证。
- 本轮没有测量真机耗时或增加新性能结论。
