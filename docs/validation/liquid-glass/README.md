# Fancam Duck · 通透玻璃界面

2026-10-18

## 调整内容

上一版仅底栏容器使用玻璃，选中态只有黄色文字，开始及设置按钮仍是独立实色样式。本轮统一导航、工具与动作按钮的视觉层次。

- 工具栏采用系统 `Glass.clear`；选中工具使用薄材质高亮，并以 `matchedGeometryEffect` 平滑移动。取消实心白色开始按钮，改用文字明确的玻璃胶囊处理入口。
- 相邻玻璃控制使用 `GlassEffectContainer`，不对视频及项目列表内容叠加玻璃。
- 底栏仅保留选人与构图，使用 SF Symbols `person.crop.circle`、`crop`；处理入口改为带文字的玻璃胶囊。
- 截取直接集成在时间轴两端，松手后保存；移除独立片段和运镜入口，新项目默认为柔和跟随。运镜算法与历史项目的已存参数保留。
- 首页改为同一深色底、项目卡片及悬浮玻璃导入入口；保留原生相册选择与历史侧滑删除。
- 指引页使用系统半屏呈现及原生图标；处理暂停／继续、异常纠正与编辑页使用同一组玻璃控件。
- 导出预览、画质菜单、保存、返回调整与分享使用同一风格。
- 保持编辑页不滚动、原片全览选人、设置原位展开与构图手势。
- 玻璃效果应用在完整按钮层，保持 44pt 图标按钮、56pt 开始／导入入口的触控区域与无障碍标识。
- iOS 26 使用原生玻璃，旧版本回退系统 Material；遵循系统降低透明度与减少动态效果设置。

API 依据：[Apple — Applying Liquid Glass to custom views](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。

## 系统外观

最终检查发现 iPhone 17 Pro 模拟器的系统玻璃外观为 `Tinted`，降低透明度与增加对比度均关闭。本轮保留该系统偏好。Tinted 比 Clear 更不透明，见 [Apple 显示设置说明](https://support.apple.com/en-lamr/guide/iphone/iphd6804774e/ios)。应用仍使用 Clear 材质并遵循系统外观。
