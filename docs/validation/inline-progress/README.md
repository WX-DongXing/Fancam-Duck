# 编辑页内联处理进度

- 处理时继续使用原编辑页面，保留原片、实时目标框、当前时间与时间轴；时间轴在处理中、暂停时只读。
- 开始处理时动画收起设置和选人／构图工具，底部原主按钮扩展为通栏，左侧「处理中」和暂停图标，右侧实际百分比。取消独立大圆环。
- 整块胶囊均为触控区域，点按暂停，显示「已暂停」及保留的百分比，再点继续。身份不确定仍阻塞并原位重新选人，完成后沿用导出流程。
- 过渡仅关联处理状态变化，避免每次进度刷新都动画重排；减少动态效果时关闭过渡。
- 处理按钮内新增柔和金色进度填充，从左向右按实际进度增长，右侧百分比继续保留。填充不参与布局和触控，暂停时停止推进，减少动态效果时不播放宽度插值动画。[填充与暂停复测](fill-summary.json)
