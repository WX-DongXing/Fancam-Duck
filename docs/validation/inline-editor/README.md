# 原位展开编辑器 · 实现与验证

日期：2026-10-18

## 本轮实现

- 默认显示完整原片，支持点选人物；构图工具打开后才进入 9:16 裁剪预览。
- 底部固定「选人／片段／构图／运镜」工具栏，右侧独立 56pt 圆形开始按钮。iOS 26 使用系统玻璃材质，iOS 18 使用系统 Material。
- 点击工具，以 0.3 秒平滑布局动画在时间轴与工具栏之间展开设置；收起后不保留空白。遵循系统“减少动态效果”。
- 设置区采用小型 ×／✓ 图标、44pt 触控区域。片段和运镜使用草稿，确定后提交；取消恢复原值。切换工具提交当前有效设置。
- 片段工具拖动边界时预览对应原片帧，支持扩展到已保存片段外；取消还原进入工具前的预览时间。
- 构图支持双指缩放、拖动、缩小／居中／放大与原生全身优先开关。取消恢复先前构图，确定后继续使用同一 CropPlan 导出。
- 分辨率移至导出页原生菜单，按素材裁剪能力从小到大排列。
- 处理过程显示真实跟踪框，支持暂停／恢复；身份不确定时阻塞并直接重新选人。历史侧滑删除流程保留。
- 修复同时提交裁剪两端时的 Swift 排他访问崩溃；修复任务取消可能与解码取帧发生冲突的竞态。

## 验证结果

- iPhone 16e / iOS 26.3.1：完整回归 70 项通过、6 项按条件跳过、0 失败，涵盖核心单元与界面测试。另通过超大字体及原生导出画质菜单专项测试。
- 横屏、方形、竖屏、超宽、超窄五种比例：保持原片比例，无页面滚动；设置展开时底栏与开始按钮位置不变。
- 方形 5 秒、竖屏 6 秒真实素材：通过相册导入、选人、构图、跟踪和实际导出。
- iPhone 17 Pro / iOS 26.3.1：桌面原始视频 `video_1774105867371.mp4`，3840×2160、37.92 秒、25fps。识别到至少五个人，完整执行选人、缩放拖动、暂停恢复、导出、返回构图并核对保存值。
- 最终输出：1080×1920、25fps、948 帧；视频 37.920 秒，原音 AAC 37.919025 秒，均从 0 开始；全片解码无错误。
- 在 0、5、18、32、37.8 秒对比成片预览与编码输出，相关度最低 0.9991959，最大平均 RGB 误差 0.0045914。处理前确定的构图锚点在处理和导出后保持不变。
- 本轮模拟器实测跟踪约 65.93 秒、导出约 59.41 秒。运行期间有其他模拟器回归任务，这些数字仅记录本机模拟器过程，不代表 iPhone 真机性能。
