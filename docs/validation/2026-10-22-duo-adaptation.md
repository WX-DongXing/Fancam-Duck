# Duo 预览布局适配验证

最新结果：已补充 iPhone Duo／iOS 27.1 实际模拟器验证。此前替代验证和未验证说明为历史记录，当前边界见本页末节。

日期：2026-10-22。实现依据为用户最后提供的外屏、内屏／书本横向、内屏竖向布局草图。

## 实现

- EditorView 的预览阶段改为复用现有工具与设置内容的浮动工作台。分析、身份阻塞和手动框选沿用原流程，Mac 沿用桌面工作台。
- compact 有侧边安全区或横向窗口采用侧边竖向工具；regular 横向采用底部左时间轴／右工具；regular 竖向采用底部时间轴／工具上下排列。普通手机竖屏仍使用底部工具。
- 进度条始终可见可操作；面板高度使用实际内容，关闭不改变画布尺寸。矮窗口的设置内容可局部滚动，不缩小触控区。
- iOS 27.1 查询活跃 division 保留区域，增加横向两个控制分区的间距；Catalyst 不编译该 iOS API。没有按机型名称或全局屏幕尺寸判断布局。
- iPhone 的方向声明增加左右横屏；原工程文件其余本地改动保持不变。

## 后续 CR：对其他模式的影响及修正

审视范围为本次 Duo 布局改动、调用它的普通手机／分析／身份确认／导出／成片兼容态和 Catalyst。按单用户本地视频编辑负载评估；未将并行中的商店素材、签名与其他工程改动纳入本次修改。

### 1. P2：横屏启用后，分析与导出仍按竖屏空间组织

- 触发：普通 iPhone 新启用横屏，安全区内工作区约 734×281pt。旧 WorkspaceLayout 要求高度至少 440pt，仍纵向排列视频和 180／244pt 的确认面板；同时 regular size class 又会选用全高检查器。
- 问题：画布空间不足，控制内容和容器的排列决策也可能不一致；窄 regular 窗口同样受影响。
- 修正：EditorView、ExportView 与 WorkspaceArrangement 共用工作区尺寸和同一个分栏判断，计入 18pt 外边距。满足最小空间时横排，矮窗口只滚动侧边操作区；普通竖屏保持原布局。
- 不修正的影响：用户横屏时可能看不到完整视频、确认或导出操作。

### 2. P2：设置滚动被当作关闭面板

- 触发：窄横屏设置超出高度，ViewThatFits 使用 ScrollView；PreviewSettingsSheet 原先仍在整个面板上同时识别下拉关闭。
- 问题：向下滚动查看设置时可能移动或关闭整张面板。
- 修正：只有需要局部滚动时，内容手势交给子视图；抓手点击／下拉和辅助功能关闭继续保留。能够完整显示内容时保留原本的整体下拉行为。
- 不修正的影响：设置内容难以浏览，滚动会意外关闭面板。

### 3. P2：宽屏模式缺少设置面板高度上限

- 触发：iPhone Plus 横屏是 regular 宽屏布局，原实现只限制 outer 模式的面板高度。较高的打码内容会挤到顶部边界。
- 修正：所有预览布局都按剩余高度限制内容，并实测各工具的理想高度；只有放不下才使用局部滚动。
- 不修正的影响：部分面板控件或抓手可能被裁掉，无法操作。

### 4. P2：兼容成片编辑态重复显示保存操作

- 触发：generateAfterAnalysis 兼容链路可让 EditorView 进入 completed；横向 expandedControls 的内容区与底部 bottomToolbar 都包含 completedActions。
- 修正：completed 时跳过底部重复工具栏，仅保留一组原有成片操作；检查器标题显示“成片预览”。
- 不修正的影响：重复操作按钮与“主角选择”标题会误导用户。
- 验证边界：已核对 AppModel 的 completed/editor 调用路径与最终视图条件；未单独自动化模拟兼容成片编辑态的 UI。正常导出完成态已通过 UI 用例。

### 修正后的验证

- iPhone 18 Pro / iOS 27.0：分析、手动确认与回到预览 3 项 UI 测试通过；保持身份阻塞，不越过待确认帧。
- iPhone 18 Pro / iOS 27.0：最终预览专项 4 项通过、0 失败，覆盖旋转状态、画布稳定、时间轴、播放／跳转、设置滚动不关闭、打码参数保留及导出；新增分栏边界单元测试 1 项通过。
- iPhone 16 Plus / iOS 18.2：regular 横屏下设置滚动／面板边界／导出完成专项 1 项通过、0 失败。
- Mac Catalyst：最终 Debug 构建通过；git diff --check 通过。
- 更新既有分析确认测试中的旧“预览设置／分段工具”断言，以当前“预览／浮动工具”交互验证完整身份确认流程。

本轮未修改 AppModel、播放器绑定、视频裁剪／打码合成、任务取消或持久化；PlayerSurface 仍按对象身份复用 AVPlayer。没有新增依赖，没有提交／推送。Duo 真机折叠、Mac 窗口交互和真实视频性能仍未实测，不能以这些专项结果宣称全模式／全量套件通过。


## iPhone Duo 实际模拟器验证

2026-10-22 在当前可用的 iPhone Duo／iOS 27.1（24A94425）上重新构建并安装，工具链 Xcode 27.1（27A9275）。通过 Device Hub 的 Closed／Partially Open／Open 与旋转控制切换实际设备姿态，没有用普通 iPhone 或 iPad 替代。

### 实际发现并修正

1. **书本半折收起面板后，播放按钮回到曲面中央。** 改为使用 division 的实际位置分配左右宽度，面板、工具和进度条各留在自己的区域；播放在有活跃纵向折叠区域时始终留在左侧，不仅在面板展开时避让。侧边系统安全区会让内容中点偏离物理铰链，所以不能只增加居中间距。
2. **桌面半折的播放按钮贴近横向曲面。** 视频与播放改为留在折叠区域上方，面板高度根据折叠区域下沿计算；进度条和工具留在底部。设置开关仍不改变该姿态的画布尺寸。
3. **外屏横放时安全区扣除后，原分栏门槛仍过宽。** 594pt 级别工作区无法放下原要求，手动框选画布被挤到时间轴附近。将画布下限调整到 220pt，检查器在 320～360pt 内随可用空间收缩，计入 20pt 间距和 18pt 边距；Duo 外屏横放的手动纠正回归通过。

### 当前通过结果

| --- | --- |
| Open 内屏横向 | 三工具面板开关、时间轴／播放可访问、边界与互不遮挡、画布 frame 不变、导出与返回通过；最终构建再次通过 |
| Open 内屏竖向 | 相同专项通过 |

| Closed 外屏竖向 | 相同专项通过；完整人物确认／手动框选后进入预览也通过 |

## 截图反馈后的布局修订（2026-10-22）

- 顶部导航与预览增加 12pt 间距；Mac 预览同样保留 12pt 顶部内边距。
- 横向内屏浮层与右侧工具栏左右等宽，竖直间隔 12pt，不再由左侧时间轴的高度决定浮层位置。
- Duo 外屏使用 NavigationStack + 原生 bottomBar；由 toolbarVerticalEdge 判断共享系统侧栏，工具位于系统状态区所在的同一侧栏，移除内容区内重复侧栏。系统 Toggle 保留选中语义。
- 按用户后续确认，除横向左右分区外，设置展开时覆盖时间轴，收起后恢复时间轴操作；画布几何不变。横向保持左侧时间轴可用。
- 横屏收起面板时播放行居中，打开面板时以现有 smooth 动画移到左侧；切换工具不返回中央。此规则也适用于书本半折，替代之前收起仍在左侧的规则。
- 比例、运镜速度、打码范围与样式继续使用 NativeSegmentedControl 内的 UISegmentedControl；普通设备／内屏三工具仍使用支持再次点击关闭的自绘玻璃按钮。原生工具栏仅承载需要系统侧栏的外屏工具。

验证：普通 iPhone 18 Pro（iOS 27.0）旋转及播放／调参／收起后拖动／导出两项通过；实际 Duo（iOS 27.1）外屏覆盖、内屏竖向覆盖、书本半折和桌面半折均通过三工具开关、画布稳定、播放避让及导出返回检查。横屏用例同时检查面板与工具栏两侧对齐、12pt 间距，以及收起后播放行的中心坐标。首轮书本半折出现一次首工具选中状态断言不稳定，随后同姿态完整重跑通过，未对产品状态逻辑做额外改动。截图见 [实际模拟器画廊](../design-assets/duo/simulator-2026-10-22/index.html)。模拟器演示素材验证不代表真机或真实视频性能验收。

最终平展横屏用例完整通过（包含三次收起居中检查）；当前源代码 Mac Catalyst 构建通过，git diff --check 通过。
