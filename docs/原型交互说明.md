# Fancam Duck 首版原型交互说明

依据产品与技术方案1.10，当前交付是可点击的界面原型，不包含Swift工程、实际人物识别、视频编解码或系统相册写入。素材使用四名舞者的动作示意，进度和恢复结果均为演示。

## 核心页面

| 页面 | 主要交互 | 下一步 |
| --- | --- | --- |
| 项目入口 | 指引视频预留、相册直达、左滑并确认删除 | 视频编辑工作台 |
| 视频编辑工作台 | 首帧选人、统一裁剪时间轴、悬浮设置、原位处理进度、原片/竖屏、身份与构图纠正、关键帧、撤销 | 导出设置 |
| 导出设置 |
| 导出设置 | 检查画幅、分辨率、声音和时长，查看未确认问题，开始或取消导出 | 完成页 |
| 导出完成 | 保存权限允许或拒绝、文件保存示例、系统分享示例、继续编辑 | 预览或项目入口 |

## 主流程

导入舞蹈视频 → 相册选择示意 → 视频编辑工作台 → 点选舞者 → 页面内确定 → 原位处理 → 同页检查与纠正 → 导出。选人、设置和纠正不再分别设计页面；处理状态也留在工作台。导入时显示首帧人物，可先调范围与参数。点选人物仅高亮并进入待确定状态，不立即分析；点击视频下方“确定舞者并开始处理”后原位处理。未选择人物时确定按钮不可用。已有结果重新选人时在原画面确认并重算。

视频为主体，直接点击画面人物框选中目标，取消独立选人按钮。视频下方依次为确定操作、播放与裁剪时间轴、内嵌“设置/纠正”工具区。设置默认显示，切换工具区只替换同页内容；无弹窗、遮罩、悬浮卡片、关闭或收起操作。处理后切换到原片即可直接点选其他人物，确定后重新处理；待确定时禁用导出。

分辨率基于旋转校正后的源视频尺寸和9:16可用裁剪区域，选项从小到大排列，不默认放大。当前演示源为1920×1080，显示360×640、540×960及606×1078原生裁剪档；4K横屏源可提供1080×1920。真实App须使用导入文件元数据，当前原型未读取真实相册。

原型上方的页面选择器仅供评审快速定位，不是正式App导航。正式App通过页面按钮推进。

## 重点评审流程

### 首页指引视频

首页原动作示意区域改为指引视频预留位，显示播放入口与操作步骤。未接入视频时明确说明待补充，不伪装为可播放的真实视频。正式指引将介绍导入、选人、生成及纠正流程。

### 项目左滑删除

最近项目向左滑动后显示删除按钮，向右滑动或轻触卡片可收起；项目操作按钮提供鼠标及键盘等效入口。点击删除先确认，取消保留项目；确认后移除项目并展示空状态，原相册视频不受影响。原型只操作演示项目记录。再次导入可创建新项目。

### 手动范围优先

导入与选人页只保留一条缩略帧带，左右拖柄调整起终点，中间播放头定位画面。键盘方向键微调，Shift配合方向键增大步长，Home和End定位允许范围边界。最短片段0.5秒。手动调整后明确说明不被自动确认覆盖，恢复自动范围需主动点击。

### 漏检恢复

在统一工作台的原视频上进入手动框选。在原视频上拖画矩形，或使用默认框。点击重新识别，进入识别中和候选确认；首次选人确认后直接开始处理，预览纠正确认后返回编辑更新目标。模拟识别失败后可以换帧、重画、退出或改用人工构图。

人物框与竖屏取景分开。手动框选不代表已持续跟踪成功，失败后的人工构图仍需要用户检查视频。

### 身份确认和构图纠正

分析完成后工作台原位显示00:22.4的交叉问题。用户可以确认原跟随正确，也可以重新指定人物。调整构图只保存位置和人物大小关键帧，不更换跟随对象。关键帧支持定位、删除和撤销最近一次修改。

### 导出与权限

尚有未确认问题时，导出页面提醒并允许返回检查。用户仍可继续演示导出。完成页模拟相册权限拒绝后的文件保存路径；不会申请真实系统权限或写入视频。

## 当前交互精度

已实现页面与面板跳转、首帧点选后确定处理、统一帧带的起终拖柄和播放头、参数滑杆、播放示意、矩形框选、候选确认、关键帧记录和导出状态。矩形调整采用重新框选，构图位置用滑杆示意。双指缩放、时间轴放大及逐帧吸附、多级撤销重做、真实系统选择器和全片关键帧插值属于后续交互细化；当前不将这些效果视为已完成。

本轮改动完成脚本语法检查。自动浏览器检查受到file协议访问策略限制，更新后的指引位、左滑删除、相册示意、拖柄和首帧直处理仍需在右侧原型中人工评审，不沿用之前版本的浏览器验证结论。

运镜预览展示目标保持在竖屏中心及大小变化，用于评审画面与操作关系，不用于评价真实模型精度、完整动作保护或算法运镜质量。

## 设计方向

采用克制的剪辑工作台布局，绿色表示主操作与目标选中，暖色问题区间同时附带文字说明。主操作每页保持单一，视频与目标优先。用户界面不显示模型名称和轨迹编号。

接下来评审统一工作台的视频占比、内嵌工具区密度、原片与竖屏切换、同页选人及纠正，以及源视频适配分辨率的表达。确认后再细化手势与异常状态，然后进入应用实现。


### 纠正入口显示规则（最新交互约定）

正常导入、选人及跟踪状态不显示纠正操作，也不使用禁用按钮占位。只有分析实际产生目标漏检、目标丢失或身份匹配不确定事件时，才在同页显示带时间点和原因的异常入口及纠正工具；构图设置保持独立于异常状态。处理中可先继续分析，用户点击异常时定位相应画面并暂停处理，避免边纠正边变更结果。确认目标正确或重新识别恢复后清除对应异常；全部异常解决后隐藏纠正工具并返回设置区域，暂停的处理继续。单纯保存构图关键帧不清除身份异常。初次选人漏检时仍保留手动框选入口。

原型在演示进度达到56%时模拟22.4秒的身份匹配异常，用于评审入口出现、定位和消失；这不是实际模型检测结果，真实实现须由异常事件驱动。


### 确认处理与自动进入导出（最新流程）

编辑阶段底部主操作统一为“确认并开始处理”，未选人时禁用。画面中的人物选择只高亮，视频下方不重复放置确认按钮；用户完成时间范围与参数设置后在页底确认。处理完成且没有未解决的识别异常时自动进入导出页，编辑页不再提供“导出视频”按钮，也不增加中间完成确认。实际编码仍需在导出页点击“开始导出”。

发现漏检、丢失或身份不确定时暂停处理，页底改为“定位异常并纠正”；解决后继续原处理任务，全部完成后自动进入导出页。原型模拟56%进度的身份异常；确认原目标、点选正确人物后确定、或手动框选识别确认均可继续。存在未解决异常时不能通过“继续处理”跳过。自动进入导出只属于本次确认发起的处理任务，打开已有项目不会自行跳转。


### 识别异常必须阻塞（最新规则，覆盖之前可仅确认原目标的说明）

一旦处理发现目标漏检、目标丢失或身份匹配失败，立即停止进度推进，保存检查点，定位异常画面，自动显示同页人物纠正区。旧目标不作为已确认候选沿用，用户必须重新点击画面人物，或手动框选并完成候选识别确认。未选择时底部显示禁用的“选择人物后才能继续”；明确选择后变为“确认目标并继续处理”。不提供“确认原人物正确”或跳过异常的捷径。

仅选择不自动继续，确认后才清除本次异常并从检查点继续；新的异常再次阻塞。异常存在时即使暂停标记被改变也不得推进，不允许进入导出页。构图修改、播放、退出框选均不解除阻塞。处理完成后自动进入导出页。


### 相机式单屏编辑（最新布局，替代下方内嵌设置区）

编辑页禁止纵向滚动。可用高度按顶部安全区、导航、视频主体、紧凑时间轴和底部确认操作划分，视频区域弹性适配高度。取消设置列表和编辑工具标签；分辨率、全身保护浮在画面顶部，人物大小、跟随速度、水平位置及手动框选浮在画面底部。轻点参数后仅在视频内显示对应的一行滑杆或选项，再次点击收起，不创建弹窗或遮罩；选项仍从小到大。底部设置不挤占时间轴及确认按钮。

首帧人物直接点选，页底确认处理。识别异常阻塞、提示与候选确认也占用原视频内的控制区域；手动框选使用视频底部短提示和默认框/换帧/退出操作，页底主按钮依状态变为识别或确认候选，无新增纵向区域。处理成功自动进入导出。原型单屏布局使用可视高度约束；自动浏览器验证仍受本地页面策略限制，真实iPhone安全区、横竖屏及动态字体适配须在应用阶段验证。


### 处理中的动态目标框

处理时视频画面随分析时间推进，持续绘制选中舞者的目标框和“正在跟随·舞者N”标签。目标框跟随当前人物位置与动作范围更新，与9:16取景框区分；不会显示全体人物选择框。用户暂停后冻结当前画面与目标框。身份匹配异常时隐藏可信跟踪框，定位问题画面并展示重新选人框，阻塞等待确认；恢复处理后继续显示新目标框。该覆盖层只用于编辑预览，不烧录到导出成片。当前为示意人物动画驱动，不代表真实模型追踪结果或处理速度。
