# 模拟人物设计素材

项目设计文档使用几何绘制的模拟人物及应用纯演示流程截图，人物、时间轴和项目缩略图不使用真实视频。更新日期：2026-10-19。

## 素材目录

- `baseline`、`face-*`、`person-*`：由几何图元绘制的静态效果示意，PNG 用于页面，JPEG 供历史文档兼容。它们解释遮挡范围和样式，不是实际打码算法输出。
- `phone`：通过隔离的模拟项目库与演示模式采集的手机界面。
- `duo`：展开、半折叠、外屏及模拟项目库的设备截图。
- `mac`：Mac Catalyst 演示流程和隔离模拟项目库截图。
- [替换清单](replacement-manifest.json)：原路径、原文件摘要、对应模拟素材及视频迁移记录。

字节完全相同的重复图片已删除，文档统一引用保留的主素材，不保留旧路径或符号链接。替换清单中的 `replacedImages.path` 仅记录历史来源，`deduplication.removedImages` 记录已删除路径与保留素材的对应关系。真实人物内容已用对应功能的当前模拟示例替换；部分截图的画幅、时长和界面版本因此与原验证记录不同。历史性能和测试 JSON 保留，不得把新示意图作为原测试逐帧输出证据。

旧的 `docs/screenshots` 目录已清理：其余 10 张未被文档、代码或测试引用的历史界面截图已删除。当前设计展示素材集中在本目录；替换清单中出现的旧路径仅用于追溯。

## 重新生成

几何示意图不依赖原始照片：

```sh
swift -module-cache-path /tmp/fancamduck-doc-module-cache tools/docs/generate_mock_scenes.swift
```

应用截图采集示例位于 `tools/docs/DocumentationMockCaptureTests.swift.example`。需要采集时临时放入 UI 测试 target，指定单个测试方法运行，从 xcresult 导出附件后移除临时测试文件。使用 `--ui-test-history` 隔离存储，使用 `--demo-editor` 显示绘制人物。图片样式采集前，先通过 `xcrun simctl addmedia <设备标识> docs/design-assets/face-image.png` 导入模拟图，确认它是图库最新图片后再选择。截图前确认系统图片选择器已关闭、界面已完成载入，不能保留相册中的真实人物缩略图。

Duo 展开与外屏是不同显示面，采集时确认对应 display，排除休眠黑屏。Mac 使用模拟项目库或体验演示，不能把本机真实项目库截图混入。

## 替换范围

本次仅处理文档展示素材，不改变应用业务逻辑、模型、真实测试 fixture 或历史测量数据。文档目录中的原真实视频已移到本机临时备份目录 `/tmp/fancamduck-original-doc-videos-20261019`，页面改用静态模拟图，不再嵌入视频；这些视频原本未被 Git 跟踪。

本次不改写既有 Git 历史，旧提交仍可能包含此前的设计截图。新增设计文档继续遵循模拟素材规则。

更新主素材后，引用它的文档会读取新内容；重新生成或采集截图时不要重新写入重复副本，并重新检查文档链接及替换清单中的摘要。
