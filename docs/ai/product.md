# 产品规则与交互约束

## 产品名称

中文名「直拍鸭」，英文名「Fancam Duck」，突出从群舞视频中剪出个人直拍。工程与 Scheme 使用 Fancam Duck，Swift 模块与标识符使用 FancamDuck，测试模块使用 FancamDuckTests／FancamDuckUITests。中文系统显示直拍鸭，英文系统显示 Fancam Duck。签名 Bundle ID 保留 com.aicut.app，保证已有安装仍可访问自己的数据。Application Support 默认使用 Fancam Duck；首次打开时仅在新目录不存在的情况下迁移旧 AICut 数据目录，不覆盖已有新目录。

首页手机标题、宽屏标题和 Mac 侧栏使用同一 A1 鸭子 Logo（`BrandLogo`），与系统 AppIcon 共用母图。Logo 仅用于品牌位置，功能按钮保留语义图标。

## 核心流程

导入视频 → 全览选主角与时间范围 → 分析并保存主角与人群结果 → 构图／打码即时设置 → 生成视频 → 同一工作台预览与导出。返回修改复用已有分析，再按新设置生成。

初次打开显示完整原片，通过 aspect fit 容纳不同视频比例，不能直接裁成单人画面。点击人物只完成选择，需明确点击“分析所选片段”后启动分析；首次分析前可以更换主角，分析后只在身份阻塞时重新指定同一人物。手动框选是重新识别的区域，必须确认并解析为人物候选，不能直接冒充稳定身份轨迹。

## 编辑页

- 手机编辑页不滚动；时间截取直接集成于共同时间轴，不恢复独立的“片段”入口。
- 构图、打码在原页面展开设置区域。模式切换与生成视频同处最底部操作栏，具体设置位于其上方；保持视频为主体。
- 默认柔和运镜，保留内部功能，不恢复独立“运镜”工具按钮。
- 使用玻璃材质和 SF Symbols；旧版本的暖白布局和巨大关闭按钮不是当前设计依据。
- 分析／生成时动画隐藏设置，仅在底部状态按钮显示百分比及进度背景；暂停／取消是独立玻璃按钮，不重复放置进度卡片。
- 返回首页提示“取消”和“保存并返回”；不能仅提供一个确认按钮。
- 主角框使用主角语义，不显示供用户点选的候选数字列表。候选数量变化不应让页面重排。

## 统一视觉风格

整体遵循现有编辑页的玻璃设计语言。iPhone 的选人／选段、分析中、分析暂停、分析完成后的设置、生成中及成片预览／导出操作区域，应使用一致的玻璃材质、圆角、描边、间距和胶囊按钮。编辑流程使用同一个工作台的不同状态，保持视频、时间轴与页面框架稳定；状态改变时切换底部控件和功能可用性，使用短促的淡入淡出或小幅位移动画，并尊重系统减少动态效果设置。状态信息与操作按钮分开布局，按钮各自拥有独立玻璃表面，不再用大卡片同时包裹状态和按钮。不能随阶段切换成另一套实色卡片风格。构图、打码设置沿用现有控件和布局；新增流程页面复用它们的视觉规范。

原生界面优先复用现有 `StudioGlassGroup`、`glassSurface` 等玻璃组件，保持背景透出、清晰的文字对比和明确的选中／禁用状态；遵循系统减少透明度等辅助功能设置。HTML 设计稿以半透明深色材质、背景模糊、细亮描边和统一圆角模拟玻璃效果，不代表原生材质的实际渲染。设计评审时同时检查各阶段的一致性和手机编辑页不滚动的约束。

## 构图

当前标签为 `16:9`、`4:3`、`1:1`，按产品的高宽约定显示。实际宽高比分别为 9/16、3/4、1；不要擅自按常见宽高标注习惯倒置。定义见 `Fancam Duck/Domain/Project.swift` 的 `OutputAspectRatio`。

支持画面拖动、双指缩放、缩小／放大、水平居中和垂直居中。单轴居中应保留另一轴及缩放。新流程设计已确认：分析完成后的设置工具只保留构图／打码，不再提供选人入口；构图和打码修改即时生效并保留配置，不提供面板级取消／完成。预览和导出应共享同一份裁剪逻辑。源画面边界仍约束可移动范围。

## 打码

默认关闭打码，由用户手动开启；开启后自动处理主角以外所有人物，不要求逐人勾选，不允许把主角作为打码对象。支持人脸和整人范围，毛玻璃、马赛克、图片一次仅生效一种。图片样式直接使用当前品牌 Logo，不跳转图片页面或打开系统图片选择器；当前仅提供一个内置素材，为后续素材扩充保留空间，不展示空入口。图片不要添加额外黑色阴影或底板，可适度放大覆盖范围。

切换打码工具保持已设置的构图，只在该构图内显示遮挡，不改变画面整体亮度。遮挡效果需要时序稳定，不能直接随瞬时检测框缩放跳变。整人矩形遮挡可能影响交叠的主角边缘，不能声称已达到分割级避让。

## 处理和导出

身份不确定必须停在问题帧，重新点选并确认后才继续。纠正仅在出现异常时提供，不作为常驻设置。普通播放与时间轴拖动不能越过阻塞，明确的相邻帧检查入口可保留。

返回编辑后，若输出配方已变化需重新生成。已有跟踪可复用时不必重新做全部身份分析，但仍需更新构图／打码与输出。导出完成页将保存相册作为底部主操作，返回调整和分享为次级操作。

## 多端

依据窗口可用空间布局，不只按设备名称判断。Duo 展开时使用主次区域，折叠／旋转保持主角、时间范围和构图状态。Mac 使用桌面工作台，提供文件导入与文件保存。新流程设计中，Mac 与 iPhone 共用工作台状态、即时生效设置、问题帧确认和独立玻璃操作按钮；Mac 仅按桌面空间采用视频与设置分栏，不引入不同的确认步骤或图片选择流程。Mac 的返回、播放、构图／打码切换、比例、位置缩放和底部操作按钮均复用同一玻璃按钮语言；选中使用更亮的玻璃底与描边，禁用降低可用性对比，不混入普通实色按钮。首页历史保留侧滑删除或等效菜单及确认，不删除相册原片。

构图／打码是不可取消选中的 Tab，进入设置默认选中构图，重复点击当前项保持选中。比例、构图／打码、打码范围与样式等互斥模式切换使用一体式玻璃分段控件：共享胶囊底座与单个浮动玻璃选中滑块，切换时滑块平移；不要拆成一排独立玻璃按钮。独立动作（生成、暂停、返回等）继续使用独立玻璃按钮。HTML 是视觉模拟，原生实现复用系统及现有玻璃组件。

Mac 设置侧栏宽 360、边距 20；设置面板内边距 16、组间距 12，分段选项内容高 44。底部模式切换和生成按钮同排等高 58，避免混用 34 高按钮。打码范围与样式采用一致的 14 号文字，底栏标签为 13。手机保持紧凑布局。
