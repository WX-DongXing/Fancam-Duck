# 产品规则与交互约束

## 产品名称

中文名「直拍鸭」，英文名「Fancam Duck」，突出从群舞视频中剪出个人直拍。工程与 Scheme 使用 Fancam Duck，Swift 模块与标识符使用 FancamDuck，测试模块使用 FancamDuckTests／FancamDuckUITests。中文系统显示直拍鸭，英文系统显示 Fancam Duck。签名 Bundle ID 保留 com.aicut.app，保证已有安装仍可访问自己的数据。Application Support 默认使用 Fancam Duck；首次打开时仅在新目录不存在的情况下迁移旧 AICut 数据目录，不覆盖已有新目录。

## 核心流程

导入视频 → 全览点选主角 → 可选时间截取、构图及打码 → 确认处理 → 原位跟踪 → 导出预览 → 导出文件 → 保存相册或分享。

初次打开显示完整原片，通过 aspect fit 容纳不同视频比例，不能直接裁成单人画面。点击人物只完成选择，需明确确认后启动处理；用户可随时在允许编辑的状态更换主角。手动框选是重新识别的区域，必须确认并解析为人物候选，不能直接冒充稳定身份轨迹。

## 编辑页

- 手机编辑页不滚动；时间截取直接集成于共同时间轴，不恢复独立的“片段”入口。
- 构图、打码在原页面展开设置区域。保持视频为主体，主要操作靠近底部。
- 默认柔和运镜，保留内部功能，不恢复独立“运镜”工具按钮。
- 使用玻璃材质和 SF Symbols；旧版本的暖白布局和巨大关闭按钮不是当前设计依据。
- 开始后动画隐藏设置，主按钮改为“处理中”，右侧保留百分比和进度背景。暂停后提供返回调整。
- 返回首页提示“取消”和“保存并返回”；不能仅提供一个确认按钮。
- 主角框使用主角语义，不显示供用户点选的候选数字列表。候选数量变化不应让页面重排。

## 构图

当前标签为 `16:9`、`4:3`、`1:1`，按产品的高宽约定显示。实际宽高比分别为 9/16、3/4、1；不要擅自按常见宽高标注习惯倒置。定义见 `Fancam Duck/Domain/Project.swift` 的 `OutputAspectRatio`。

支持画面拖动、双指缩放、缩小／放大、水平居中和垂直居中。单轴居中应保留另一轴及缩放。取消恢复进入面板前配置，确认使用当前构图；预览和导出应共享同一份裁剪逻辑。源画面边界仍约束可移动范围。

## 打码

默认自动处理主角以外所有人物，不要求逐人勾选，不允许把主角作为打码对象。支持人脸和整人范围，毛玻璃、马赛克、图片一次仅生效一种。自定义图片不要添加额外黑色阴影或底板，可适度放大覆盖范围。

遮挡效果需要时序稳定，不能直接随瞬时检测框缩放跳变。整人矩形遮挡可能影响交叠的主角边缘，不能声称已达到分割级避让。

## 处理和导出

身份不确定必须停在问题帧，重新点选并确认后才继续。纠正仅在出现异常时提供，不作为常驻设置。普通播放与时间轴拖动不能越过阻塞，明确的相邻帧检查入口可保留。

返回编辑后，若输出配方已变化需重新生成。已有跟踪可复用时不必重新做全部身份分析，但仍需更新构图／打码与输出。导出完成页将保存相册作为底部主操作，返回调整和分享为次级操作。

## 多端

依据窗口可用空间布局，不只按设备名称判断。Duo 展开时使用主次区域，折叠／旋转保持主角、时间范围和构图状态。Mac 使用桌面工作台，提供文件导入与文件保存。首页历史保留侧滑删除或等效菜单及确认，不删除相册原片。
