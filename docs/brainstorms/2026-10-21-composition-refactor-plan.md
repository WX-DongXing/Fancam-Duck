# 直拍构图重构方案

日期：2026-10-21。状态：已实现，并通过 iPhone 模拟器回归及 Mac 实际窗口检查；真实视频观感仍待验收。本文替代此前的参数菜单／滑块方案。

## 1. 本轮确定的行为

保留现有构图操作：画面比例分段选择、自由拖动、双指缩放、缩小、放大、水平居中、垂直居中。不替换为参数菜单或三排滑块，不新增设置页面。

默认稳定全身高度占成片高度 **60%**，默认水平和垂直居中。该值按用户本轮明确要求确定。此前女团抽查提出的 85% 是历史设计建议，不再作为产品默认；[调研报告](2026-10-21-girl-group-fancam-framing-research.md)及原始数据保留，不把调研结果改写为支持 60%。

用户调整的是整段持续构图目标：输出画幅比例、人物大小、水平位置、垂直位置。暂停在任意时刻调整后，更新整个所选已分析片段；向前／向后拖动和继续播放均使用最新配置。此次不引入关键帧，不按修改发生的时间累积局部构图。

例如：12 秒调成人物 70%、水平右偏 4%、垂直上偏 2%；拖到 30 秒保持同一目标。在 30 秒改成人物 80%、水平居中，则整段改用人物 80%、水平 0%、垂直上偏 2%；再回到 12 秒也显示新目标。生成使用最终配置，历史成片沿用原有“重新生成”流程。

## 2. 保留操作，改为持续生效

| 操作 | 行为与保留项 |
| --- | --- |
| 自由拖动 | 人物随手指方向移动，修改持续水平／垂直位置，不只记录当前帧 crop |
| 双指缩放 | 保留原捏合锚点和自由操作体验；从当前帧变换反推人物占比与位置，可能同时改变两轴偏移，状态数值同步更新 |
| 缩小／放大按钮 | 沿用现有按钮与步进方式，调整人物大小；保持其他轴的位置目标 |
| 水平居中 | 将水平目标偏移设为 0%，保留垂直偏移和人物大小；对整段生效 |
| 垂直居中 | 将垂直目标偏移设为 0%，保留水平偏移和人物大小；对整段生效 |
| 再点已高亮的居中按钮 | 保持居中，不切换为关闭模式 |
| 改画面比例 | 保留人物占比及两轴目标，重算整段窗口；不恢复初始裁剪 |
| 拖动时间轴／暂停／播放 | 按当前实际源时刻查询同一条镜头轨迹与主角位置，不能沿用初始时刻的框或构图 |
| 切换构图／运镜／打码 | 保留人物标识及构图，工具切换不建立新锚点，不重复人物分析 |

自由调整仅受现有最小裁剪尺寸、可容纳的输出比例与原片边界等必要约束，不新增之前建议的固定 50%～90% 大小或 10%～90% 位置限制。保留现有手势开始、取消及结束机制；取消只撤回本次未提交手势。

## 3. 预览设置显示当前主角

构图、运镜及打码工具均显示已选主角：复用现有黄色直角细框与四角短线（预览设置不显示文字标签），不增加头像卡或候选列表。它是当前时刻主角轨迹的可视化，不是重新选人入口。

- 拖动、缩放和改比例时，主角框随相同画面变换更新；暂停、播放和寻帧时跟随对应视频帧，不停留在分析起点。
- 静帧以实际显示源帧时刻、播放以实际显示帧时间为准；寻帧尚未完成时保留一致的旧帧／旧框组合，不让新时刻的框先覆盖旧图。
- 标识仅在有效预览画面中绘制并裁剪，框外标签不能遮住顶栏、时间轴或操作按钮。
- 框表达当前可见／已确认的人物区域，不把虚拟直立身高画成当前检测框；身份不可靠时沿用待确认状态，不借此跳过身份阻塞。
- 在打码工具中主角标识仍可辨，打码仍排除主角。所有框线、标签与参考线只属于编辑 UI，不进入生成视频、相册或分享输出。

## 4. 当前比例与偏移百分比

必须区分两个“比例”：画幅比例由原有分段控件显示，如 16:9；人物占比以“人物 60%”显示。沿用当前产品的高宽标签约定，16:9 标签对应实际宽高比 9/16。

两轴偏移以成片宽／高为分母，以中心为 0%，不以原片宽度、检测框宽度或剩余边距为分母：

- 水平偏移 = (稳定人体参考点在成片中的 x / 成片宽度 - 0.5) × 100%。负值显示“左 n%”，正值显示“右 n%”。
- 垂直偏移 = (稳定人体参考点在成片中的 y / 成片高度 - 0.5) × 100%。负值显示“上 n%”，正值显示“下 n%”。
- 人物占比 = 稳定全身高度 / 当前裁剪高度 × 100%。下蹲时不把缩短的可见框重新放大到 60%，举手也不因包围盒变高而自动缩小。

默认状态行：`人物 60% · 水平 0% · 垂直 0%`。手势中及停手后持续显示，同一套信息在 Mac 复用。数值四舍五入显示整数百分比，居中容差内显示该轴 0%；计算与保存保留原精度。

状态行显示**当前显示帧的实际构图值**，用户保存的目标另行保留。不显示常驻手势操作说明，也不为其预留空行。受边缘或平滑响应影响时，才按需显示必要的目标差异，例如“原片边缘：目标水平 0%，当前右 3%”或“跟随中：目标人物 60%”；不把实际偏差写回目标。提示可通过系统辅助功能读完整内容，不能依靠压缩成难以辨认的小字。

## 5. 居中按钮高亮

默认两轴目标为 0%，且可实现居中时，“水平居中”“垂直居中”分别高亮。仅高亮对应图标，不添加选中背景、不改变文字颜色；同时提供辅助功能选中状态。

每轴独立判断：该轴目标在零点数值容差内，且当前实际偏移绝对值不超过画幅对应轴的 0.5% 时，高亮该按钮。0.5% 是待 UI 验证的初始显示容差，不是允许算法长期偏位的死区；精确目标仍为 0%。

自由拖动让某一轴目标偏离零点后，该轴取消高亮，另一轴保持自己的状态；缩放没有改变位置目标时，不无故清除高亮。回到居中目标与实际位置后恢复高亮。原片边缘导致实际位置未居中时，普通高亮取消，提示居中目标因边缘受限；原目标仍保留，回到可行区域后自动恢复，不需要再次点居中。

## 6. UI 简图与多端

保留原布局与操作区，增加一行常驻的只读构图数值。下图“●”仅表示高亮状态，不是新增按钮图标。

```text
┌────────────────────────────────┐
│ ‹           预览设置             │
│                                │
│       ┌────────────────┐       │
│       │     ┌主角┐     │       │
│       │     │ ○ │      │       │
│       │     │/│\│      │       │
│       │     │/ \│      │       │
│       │     └───┘      │       │
│       └────────────────┘       │
│                 ▶              │
│ ─────────── 时间轴 ─────────── │
│                                │
│       [16:9 │ 4:3 │ 1:1]        │
│ 人物 60% · 水平 0% · 垂直 0%    │
│ [缩小] [放大] [●水平居中] [●垂直居中]│
│                                │
│ [构图 │ 运镜 │ 打码] [生成预览]  │
└────────────────────────────────┘
```

偏移后的状态示例：`人物 70% · 右 4% · 上 2%`，两居中按钮取消高亮；点击水平居中后变为 `人物 70% · 水平 0% · 上 2%`，只高亮水平按钮。

手机构图面板优先在现有约 154pt 内容纳控件，按内容布局，不再为操作说明预留固定空间。比例行仍为 48pt，四个动作按钮热区至少 44pt；状态行约 20pt，其余空间分配给间距和内边距。边缘等临时状态说明按需显示，必要时面板可增至约 184pt。视频、时间轴和底部工具维持共同布局，不通过整页滚动容纳。小屏、大字体与横屏实测后微调面板空间；辅助功能数值可合并为一个完整描述，不新增必须横向滚动才能看见的字段。

Mac／宽屏继续使用现有预览＋设置侧栏，共用同样四个按钮、数值和高亮逻辑，不改成参数菜单，不增加不同的确认流程。主角标识显示在预览里，数值放在构图面板。

## 7. 运镜与原片边界

横向优先使用可靠骨盆中心，纵向使用经可靠姿态标定的稳定全身参考中心，而不是把骨盆直接置于高度 50%。同一参考定义用于手势、居中、偏移显示和跟随；不要混用逐帧包围框中心与骨盆中心。

复用已确认主角轨迹和同身份姿态缓存，估计稳定人体尺度，滤除手臂展开、下蹲和遮挡导致的包围框变化；只有连续可靠的远近尺度变化才驱动变焦。缺少证据时保守沿用可靠尺度，不偷偷重新跑人物分析，身份不确定仍阻塞。

每个源时刻使用同一组片段目标求理想裁剪窗口，去掉当前固定纵向位置、固定缩放与横向 12% 死区的假设。舒缓／标准／灵敏只改变平移与变焦响应，不改目标构图。平滑允许短暂误差，不能把“保持一致”解释成强平滑与逐帧绝对零误差同时保证。

保留用户已确认的原片填满优先：先限制可容纳的裁剪尺寸，再限制窗口位置；允许实际占比或偏移暂时变化，不添加黑边或模糊背景。边界修正不能覆盖用户目标，恢复可行区域后平滑回归。现有 protectFullBody 不再暗中扩大取景覆盖用户占比；60% 的留白不能保证所有伸展动作完整入镜。

## 8. 实现范围与状态一致性

| 入口 | 计划改动 |
| --- | --- |
| Domain/Project.swift、ProjectStore | 版本化保存片段级人物目标，默认 60%、两轴 0%；实际逐帧值仅作为派生状态 |
| TrackingPipeline 与已关联姿态入口 | 必要时为样本增加可选稳定参考点、尺度及可靠性，保留旧缓存兼容；不改身份算法 |
| CropPlan | 生成横向、纵向及缩放轨迹，任意时刻插值中心和尺寸；移除旧固定窗口假设 |
| CompositionGeometry | 保留原手势体验，将当前帧自由变换反推为片段目标，与按钮操作共用 |
| AppModel | 统一片段目标、实际显示帧、主角框、比例数值及高亮；最新操作优先，保留任务／项目有效性检查 |
| EditorView、CompositionEditorStage | 保留四按钮，新增只读数值、主角标识、选中样式及边缘提示 |
| VideoExporter、打码与预览合成 | 统一最终轨迹、源时刻、缩放尺寸；编辑标识与输出配方隔离 |

计算链路：`已确认主角轨迹 → 稳定参考与尺度 → 片段目标 → 平滑及原片边界约束 → 任意时刻最终窗口 → 静帧／播放／时间轴／打码／导出`。

手势期间立即更新当前帧和读数，后台合并重算整段轨迹；拖动时间轴只查询，不反写新目标。重算按任务 ID、项目 ID、设置版本及实际显示时刻防止旧结果覆盖；取消、切项目、后台和删除均保留既有防护。播放使用已准备好的最新预览，避免视频用旧配方而框和读数用新配方。

## 9. 旧项目与验证

旧项目打开时保留原构图及成片，不静默重置。首次修改时在当前源时刻根据旧实际镜头反推新片段目标，再进入新模式；原锚点仅用于兼容，不能与新目标重复叠加。保存后重开恢复同一配置。旧缓存姿态不足时保守降级，不强制重跑分析。

实施顺序：目标与轨迹计算 → 任意时刻调节及共享预览／导出 → 主角框／数值／高亮 → 旧项目恢复与多端验证。

必须覆盖：

- 默认人物 60%、水平／垂直居中且两按钮高亮；两轴居中各自保留另一轴和大小。
- 自由拖动、原捏合锚点、缩小／放大行为保留，状态行同步，无菜单／滑块替换。
- 12 秒修改后跳到 5／30 秒配置一致；30 秒再次修改后回到 12 秒也应用新配置，不留下局部锚点。
- 当前时刻插值正确，非采样点、seek 合并、播放暂停、晚到解码均不出现视频与主角框／读数错位。
- 横移、纵移、远近变化、下蹲和抬手；主角框随真实姿态变化，但稳定占比不跟包围框抽动。
- 原片边缘实际偏移可解释、高亮不误报、目标未被篡改、回到内部恢复，无越界。
- 静帧、成片预览、打码和真实导出按同一源时刻与窗口；输出不含主角框及辅助线。
- 快速连续改值、切工具、切项目、取消、后台及删除不被旧任务覆盖；旧项目迁移保存后可恢复。
- 手机不滚动、Mac 窄窗口、44pt 热区、数值可读、大字体、减少动态效果及辅助功能选中状态。

位置误差与尺度误差继续量化，边缘受限单独统计；此前建议的 P95 位置误差 2%、尺度误差 3 个百分点仅为待验证工程门槛，不是已达到结果。实现验证结果见[本轮验证记录](../validation/2026-10-21-subject-composition.md)；合成轨迹与模拟人物 UI 不能替代真实群舞视频观感验收。
