01 / 应用如何处理数据

直拍鸭项目维护者不通过当前版本的应用收集你的个人数据。应用无需注册账号，不集成广告、行为分析或跨应用追踪服务，也不会将导入的视频、音频或人物分析结果主动上传到开发者服务器。

你选择的视频会复制到应用本地空间，用于人物选择、姿态检测、目标跟踪、构图、打码和导出。应用会在本机生成人体／人脸区域、姿态与人物外观特征，用于在所选视频中跟随主角及遮挡其他人物，不用于识别现实身份、建立跨项目身份档案或广告用途。

应用读取本地视频的文件大小与修改时间，仅用于检查缓存是否仍然有效。这些信息不会发送给项目维护者。

02 / 存储、保留与删除

导入副本、编辑记录、人物分析缓存及应用内生成文件存储在设备的应用空间，供继续编辑与重复生成。它们不会因为关闭应用自动删除。

你可以在首页删除项目，移除对应的编辑记录、分析缓存和应用内文件；若多个项目共用同一导入副本，该副本会在不再被其他项目引用时删除。相册中的原视频、已保存到相册或外部目录的成片不会随项目删除。

卸载应用会移除其本地应用数据；外部保存副本需要在对应相册或目录中自行删除。系统备份可能包含应用数据，是否备份及如何删除由你的设备和备份设置决定。

03 / 照片、文件与系统权限

应用通过系统照片或文件选择器读取你主动选择的视频。保存成片至相册时会请求添加照片的权限；拒绝后不会获得该权限，你可以在系统设置中调整授权。

只有当你主动保存或分享成片时，应用才会将成片交给你选择的系统目的地。分享目标对文件的后续处理适用该服务的政策。系统评价功能由 Apple 的 StoreKit 提供。

04 / 本网站与外部服务

本网站为静态信息页面，不设置账户、不提供文件上传、不使用广告、分析脚本或追踪 Cookie。

网站托管在 Vercel。访问页面时，托管服务可能为提供页面、保障安全和排查故障处理 IP 地址、浏览器信息、访问时间与请求路径等访问数据。相关处理及保留方式以 Vercel 隐私政策为准；这不意味着 App 会上传你的视频。

点击 GitHub 或其他外部链接后，将进入对应服务。向 GitHub Issues 提交问题时，GitHub 会处理你提交的内容及账号信息，请参阅 GitHub 隐私声明。公开问题中请勿上传私人视频、人脸照片、证件或其他敏感信息。

05 / 联系维护者与政策更新

如需咨询数据处理、提出隐私问题或请求删除你主动提交给项目的内容，请通过 项目 GitHub Issues 联系直拍鸭项目维护者。请仅提供处理问题所必需的信息；本机数据可按上文方式自行删除。

本应用不以收集儿童个人信息为目的。请在有权处理视频中人物和内容的前提下使用本应用。

功能或数据处理方式变化时，我们将更新本页面及日期；涉及新增数据收集或权限时，将按适用要求提供说明与授权流程。
