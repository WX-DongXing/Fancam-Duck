从一段舞蹈视频开始

  1. 导入视频，设置起止时间，点选要跟随的主角。
  2. 启动人物分析；无法确认人物时，按提示重新指定或手动框选。
  3. 分析完成后调整构图、运镜与打码，再生成视频。
  4. 预览成片，保存至照片或文件。首页「第一次使用？」提供演示流程。

常见问题

分析时为什么需要再次确认人物？

遮挡、出画或外观相似可能让人物身份无法确认。按提示指定同一位主角，确认后继续。不要把其他人物选作原主角。

为什么导出需要一些时间？

人物分析、视频裁剪与打码在本机执行，耗时取决于设备、视频时长、分辨率和画面人数。执行中请保持设备有足够电量与可用空间。

无法保存到相册怎么办？

在系统设置中检查直拍鸭的照片添加权限和设备空间，再返回重试。Mac 用户也可以选择保存到文件。

删除项目会删除相册原片吗？

不会。项目删除仅处理编辑记录及应用内副本；相册原片与已保存到外部的成片保留。

联系项目维护者

请通过 GitHub Issues 反馈问题或建议。建议附上设备型号、系统与应用版本、复现步骤以及错误文字。提交问题需要 GitHub 账号。

Issues 是公开的。请勿上传私人视频、人脸照片或敏感信息；示意图应使用模拟素材。
